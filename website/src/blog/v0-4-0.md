I rewrote the BoxBox desktop app. It's still called `boxbox`, and it now manages local files directly while letting you browse your paired BoxBox servers.

The old app bundled a browser and a private server to show the web interface. That made for a large install just to browse files. I wanted BoxBox to work more like a desktop file manager while keeping the layout I already liked.

## Desktop app

I wanted the desktop app to handle the things I reach for in a file manager every day:

- Browse local files and paired servers together.
- Mount drives, phones, network shares and encrypted volumes on Linux.
- Copy, paste and drag files between BoxBox and other apps.
- Use the system Trash and undo a rename or a move to Trash with Ctrl+Z.
- Open folders in tabs and return to your selection with Back and Forward.
- Give folders their own view, sort order, colour and emblem.
- See folder previews, file details and transfer progress.
- Use keyboard navigation, select by pattern and press F1 for shortcuts.

BoxBox runs on Windows now too. Extract the zip and run `boxbox.exe`. It works with the Recycle Bin, Explorer menus, thumbnails and network paths. On Linux there's a tar.gz with a per-user installer. AppImages and the AUR package are published separately after the release and can take longer to appear. You'll need Vulkan drivers.

## Web app

I didn't want the web app to fall behind. It now has many of the same browsing features:

- Remember view and sort choices for each folder.
- Resize or hide columns and zoom the list or grid.
- Preview folder contents and add colours and emblems.
- Open Details with F11 or view Properties for multiple items with Alt+Enter.
- Rename in place and get name suggestions when creating items.
- Select files with the keyboard, a pattern or a selection box.
- Open folders in a new browser tab and return to your selection with Back and Forward.
- Drag over folders to open them, and drop files on path crumbs and places.

## Server

There are a few changes for people running BoxBox too:

- Sign in with an OpenID Connect provider. SSO-only accounts can't pair desktop clients yet because pairing requires a password. [#250](https://github.com/jR4dh3y/BoxBox/pull/250)
- Show previews on share links, including video frames where available. [#249](https://github.com/jR4dh3y/BoxBox/pull/249)
- Map accounts to NAS users and groups on Linux so files use each person's permissions. [#266](https://github.com/jR4dh3y/BoxBox/pull/266)
- Choose to delete a shared file when its link expires. This requires a writable mount and isn't available in NAS mode. [#267](https://github.com/jR4dh3y/BoxBox/pull/267)
- Keep symlinks and file permissions when copying folders or moving them between drives. Thanks to [jayhemnani9910](https://github.com/jayhemnani9910) for this one. [#268](https://github.com/jR4dh3y/BoxBox/pull/268)

There's a [full list in the release notes](https://github.com/jR4dh3y/BoxBox/releases/tag/v0.4.0).

You can get the desktop app from [GitHub Releases](https://github.com/jR4dh3y/BoxBox/releases/) or the [download page](https://boxbox.radhey.dev/download/). On Linux, remove the old Electrobun app before running `./install.sh` from the new archive. If you already installed the native app, rerun its installer after the removal to restore its application-menu entry. Your old desktop settings won't carry over, so you'll need to set up your preferences and server connections again. The old Electrobun FileChooser portal is gone. On Linux, run `boxbox --enable-picker` to use the native app for other apps’ Open and Save dialogs.

For the server, use `ghcr.io/jr4dh3y/boxbox:v0.4.0` or `ghcr.io/jr4dh3y/boxbox:latest`. If you like BoxBox, [star it on GitHub](https://github.com/jR4dh3y/BoxBox). It helps people find the project.

I rewrote the BoxBox desktop app. It's still `boxbox`, but it's now a native Rust app built on GPUI. It manages local files directly and can still browse your paired BoxBox servers.

The old desktop app bundled Chromium, Bun and a private Go server to show the web interface. That made for a large install just to browse files. I wanted BoxBox to work more like a desktop file manager while keeping the layout I already liked.

Underneath, the new app talks to the system directly. On Linux that includes UDisks2, GVfs, freedesktop Trash, thumbnails, Wayland and X11. The first GPUI commit was on 2026-11-05. It replaced the Electrobun app on 2026-11-16, 11 days later.

## Windows and Linux

BoxBox runs on Windows 11 x64 now too. Extract the zip and run `boxbox.exe`. It works with the Recycle Bin, Explorer copy, paste and drag, Windows thumbnails, the Open With chooser, and UNC and SMB paths. There's an optional Explorer entry in `windows-explorer.ps1`.

On Linux there's a tar.gz with a per-user installer, x86_64 and ARM64 AppImages, and an AUR package. You'll need Vulkan drivers. The old desktop settings don't carry over, so you'll need to set up your preferences and server connections again. The FileChooser portal backend is gone.

## The web app gets the file manager features too

I didn't want the web app to fall behind. It now remembers view and sort choices per folder, lets you resize or hide columns, and adds zoom, folder previews, colours and emblems. There's keyboard navigation, rubber-band selection, a Details panel, multi-item Properties, in-place rename and spring-loaded drag and drop. Press F1 in the app for the shortcuts. [#272](https://github.com/jR4dh3y/BoxBox/pull/272)

A few server changes are in this release too:

- Sign in with an OpenID Connect provider. SSO-only accounts can't pair desktop clients yet because pairing requires a password. [#250](https://github.com/jR4dh3y/BoxBox/pull/250)
- Share links get previews, including video frames. [#249](https://github.com/jR4dh3y/BoxBox/pull/249)
- Map accounts to NAS user and group IDs so file operations use each person's permissions. [#266](https://github.com/jR4dh3y/BoxBox/pull/266)
- Opt in to deleting a shared file when its link expires. This isn't available in NAS mode. [#267](https://github.com/jR4dh3y/BoxBox/pull/267)
- Folder copies and cross-disk moves keep symlinks and file modes. Thanks to [jayhemnani9910](https://github.com/jayhemnani9910) for this one. [#268](https://github.com/jR4dh3y/BoxBox/pull/268)

You can get the desktop app from [GitHub Releases](https://github.com/jR4dh3y/BoxBox/releases/) or the [download page](https://boxbox.radhey.dev/download/). Reinstall using the new archive; you can remove the old Electrobun app with its own uninstall command. For the server, use `ghcr.io/jr4dh3y/boxbox:v0.4.0` or `ghcr.io/jr4dh3y/boxbox:latest`.

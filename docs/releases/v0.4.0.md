BoxBox v0.4.0 replaces the desktop app with BoxBox Files, a native file manager for Linux and Windows. The web app also gets many of the same file-manager features.

## Highlights

- A native Rust desktop app built on GPUI, with the same BoxBox layout and support for paired servers. [#248](https://github.com/jR4dh3y/BoxBox/pull/248)
- Windows 11 x64 desktop support, alongside Linux x86_64 and an ARM64 AppImage.
- More capable browsing and selection in the web app. [#272](https://github.com/jR4dh3y/BoxBox/pull/272)
- OpenID Connect sign-in, NAS identities, and improvements to shares and file operations.

## Desktop

BoxBox Files manages local files directly and browses paired BoxBox servers through their API. On Linux it uses UDisks2, GVfs, freedesktop Trash, system thumbnails and Wayland or X11. The command is `boxbox-files` and the desktop ID is `io.boxbox.files.desktop`. [#248](https://github.com/jR4dh3y/BoxBox/pull/248)

For Windows 11 x64, extract the zip and run `boxbox-files.exe`. The app supports the Recycle Bin, Explorer copy, paste and drag, Windows thumbnails, the Open With chooser, and UNC and SMB paths. Run `windows-explorer.ps1` if you want the optional "Open in BoxBox Files" Explorer entry. A Direct3D 11-capable driver is required.

On Linux, the tar.gz includes a per-user `install.sh` that needs no sudo. Use `--set-default` to make it the default file manager or `--uninstall` to remove it. AppImages are available for x86_64 and ARM64, and there is an AUR package. The app needs Vulkan drivers, such as `mesa-vulkan-drivers`, in place of the old WebKitGTK and CEF dependencies. See the [desktop guide](https://boxbox.radhey.dev/docs/desktop/).

## Web app

The web app gets per-folder view and sort, resizable and hideable list columns, zoom, folder previews, colours and emblems, and hover cards. [#272](https://github.com/jR4dh3y/BoxBox/pull/272)

- Use GTK-style keyboard navigation, rubber-band selection, Ctrl+S to select by pattern, Ctrl+I to invert selection, and F1 for shortcuts. Back and forward restore your selection.
- Set a start location, use place menus on crumbs, drives and places, open Details with F11, and open multi-item Properties with Alt+Enter. Rename files in place.
- Drag over a folder to open it while dragging. Ctrl copies, Shift moves, and Alt asks which action to use. Settings now has an About page.
- The server adds `GET /api/v1/files/peek/{path}` and `POST /api/v1/files/properties` for the new views and properties.

## Server

- Sign in through an OpenID Connect provider, alongside or instead of passwords. Accounts that only use SSO cannot pair desktop clients because pairing requires a password. [#250](https://github.com/jR4dh3y/BoxBox/pull/250)
- Share links show previews, including video frames where available. [#249](https://github.com/jR4dh3y/BoxBox/pull/249)
- On Linux, map BoxBox accounts, including SSO accounts, to NAS user and group IDs so file operations use each person's permissions and ownership. [#266](https://github.com/jR4dh3y/BoxBox/pull/266)
- Choose to delete a shared file when its link expires. This is opt-in and needs an expiring file share on a writable mount. It is unavailable in NAS mode. [#267](https://github.com/jR4dh3y/BoxBox/pull/267)
- Folder copies and cross-disk moves keep symlinks and file modes. [#268](https://github.com/jR4dh3y/BoxBox/pull/268)

## Upgrading

Back up your persistent server data and preserve your configuration, credentials, JWT secret and data volume. Update the Docker image to `ghcr.io/jr4dh3y/boxbox:v0.4.0` or `ghcr.io/jr4dh3y/boxbox:latest`.

Desktop users should install the new archive. The old Electrobun installation can be removed with its own uninstall command. See the [desktop guide](https://boxbox.radhey.dev/docs/desktop/) for installation and pairing.

## Breaking changes

- Desktop settings from the Electrobun app are not migrated. Set up your preferences and server connections again.
- The FileChooser portal backend has been removed.
- The desktop command and ID are now `boxbox-files` and `io.boxbox.files.desktop`.

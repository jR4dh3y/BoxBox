BoxBox v0.4.0 brings a new native desktop app for Linux and Windows, more ways to browse in the web app, and new options for server owners.

## Highlights

- Browse local files and paired servers in the new `boxbox` desktop app.
- Use BoxBox on Windows as well as Linux.
- Customize folder views and navigate files more easily in the web app.
- Sign in with an OpenID Connect provider and use NAS account permissions.

## Desktop app

- Browse local files and paired BoxBox servers in one app.
- See drives, devices and their available space in Overview.
- Mount and eject drives, phones, network shares and encrypted volumes on Linux.
- Copy, paste and drag files between BoxBox and other apps.
- Use the system Trash, restore files, or delete them permanently with Shift+Delete.
- Undo a rename or a move to Trash with Ctrl+Z.
- Open files with your chosen app and use your system's file icons and thumbnails.
- Use Windows Explorer menus, the Recycle Bin and network paths.
- Open folders in tabs and return to your selection with Back and Forward.
- Choose a start location and type or complete a path in the address bar.
- Find files with search, or select them by dragging, by pattern or with the keyboard.
- Remember each folder's view and sort order, zoom, and resize list columns.
- Preview folder contents and customize folder colours and emblems.
- See file details with F11 and edit permissions in Properties.
- Create links, compress files and create files from templates.
- Watch transfer progress and cancel transfers.
- Pin and reorder favourite folders, and browse Recent, Templates and Network places.
- Press F1 to see the keyboard shortcuts.

For Windows, extract the zip and run `boxbox.exe`. On Linux, the tar.gz includes a per-user installer. AppImages and the AUR package are published by separate jobs after the release goes live and may be delayed or unavailable if those jobs fail. See the [desktop guide](https://boxbox.radhey.dev/docs/desktop/).

## Web app

- Remember each folder's view and sort order.
- Resize or hide list columns and zoom the list or grid.
- Preview folder contents and customize folder colours and emblems.
- See item details by hovering or opening the Details panel with F11.
- View Properties for multiple items with Alt+Enter.
- Rename in place and get name suggestions when creating files and folders.
- Navigate and select files with the keyboard, by pattern, or by dragging a selection box.
- Open folders and path crumbs in a new browser tab with a middle-click.
- Return to your selection with Back and Forward, and choose where the app opens.
- Use menus on path crumbs and sidebar places to open, paste and copy paths.
- Drag files over folders to open them, or drop them on path crumbs and places.
- Press F1 to see the keyboard shortcuts.

## Server

- Sign in with an OpenID Connect provider, alongside or instead of passwords. SSO-only accounts cannot pair desktop clients because pairing requires a password. [#250](https://github.com/jR4dh3y/BoxBox/pull/250)
- Show previews on share links, including video frames where available. [#249](https://github.com/jR4dh3y/BoxBox/pull/249)
- Map accounts to NAS users and groups on Linux so file access uses each person's permissions and ownership. [#266](https://github.com/jR4dh3y/BoxBox/pull/266)
- Choose to delete a shared file when its link expires; this requires a writable mount and is unavailable in NAS mode. [#267](https://github.com/jR4dh3y/BoxBox/pull/267)
- Keep symlinks and file permissions when copying folders or moving them between drives. [#268](https://github.com/jR4dh3y/BoxBox/pull/268)

## Upgrading

Back up your persistent server data and preserve your configuration, credentials, JWT secret and data volume. Update the Docker image to `ghcr.io/jr4dh3y/boxbox:v0.4.0` or `ghcr.io/jr4dh3y/boxbox:latest`.

On Linux, remove the old Electrobun installation before running `./install.sh` from the new archive. The old removal also deletes the shared application-menu entry. If you already installed the native app, rerun its installer after removing Electrobun to restore the entry. See the [desktop guide](https://boxbox.radhey.dev/docs/desktop/) for installation and pairing.

## Breaking changes

- Desktop settings from the Electrobun app are not migrated. Set up your preferences and server connections again.
- The FileChooser portal backend has been removed.

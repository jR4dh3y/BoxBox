# BoxBox v0.4.0

BoxBox v0.4.0 replaces the old Electrobun desktop app with a native Rust/GPUI rewrite. It keeps the same look, adds Windows support alongside Linux, and drops the bundled browser, Bun runtime, and private Go server for a single binary. The desktop app is still `boxbox`.

## Desktop app

### Local files, paired servers, and drives
- Browse local files and paired BoxBox servers in one window. Pair servers with a code from server settings (`Settings -> Account`); credentials stay in your system keyring.
- Paired servers connect in the background at launch and show their drives beside local disks in Overview and the sidebar, holding their slots while connecting so the layout stays steady.
- Unified Overview and Drives list showing the system drive, internal data partitions, removable drives, phones, encrypted volumes, network shares, and paired server drives with used/total space.
- Rename drives and reset names; custom names persist across unplugging.
- On Linux, mount, unmount, and eject drives, MTP phones, locked LUKS volumes (with passphrase prompts), and network shares (`smb://`, `sftp://`, `ftp://`, `mtp://`) with readable error messages when mounting fails.
- Sidebar adds Recent, Templates, and Network (local share discovery) places, plus right-click menus on every sidebar entry.
- Local favourites sync with GTK bookmarks. Drag folders onto Favorites to pin them, and drag to reorder.

### Navigation, tabs, and search
- Single-instance windows: launching a folder or using "Show in folder" from another app opens a new tab in the running window.
- Tabs and split panes. New tabs duplicate the current folder right away without flashing a reload; middle-click folders or path crumbs to open in a new tab (`Ctrl+middle-click` opens in the background).
- Back and Forward (including mouse side buttons) restore your selection and scroll position, skip deleted folders, and have right-click history menus.
- Start location setting (`Settings -> General`): Overview, Home, or Last location.
- Breadcrumb path bar shows the full path, folds long paths into `...`, has right-click menus, and accepts drops. Click empty space or the current folder to edit paths (`~/...`, `file://`, network URIs) with Tab completion.
- Streaming search (`Ctrl+F`) with multi-word and glob (`*`, `?`) matching, relevance ranking, and folder paths shown on each result.

### Views, customization, and inspection
- Per-folder List/Grid view and sort order, with a setting to share one view across all folders.
- Zoom list and grid views with `Ctrl +`/`-`/`0` or `Ctrl+wheel` (replaces Compact rows).
- Resizable and hideable list columns (`Name`, `Size`, `Type`, `Modified`) across folders, Trash, and the file picker, with double-click to reset and horizontal scrolling.
- Grid folder previews show up to three items inside local folders.
- **Customize Folder** lets you set a folder's colour, searchable Lucide emblem, and emblem colour (saved by real path so symlinks match). Special folders get corner emblems.
- Pick between your system icon theme, BoxBox tinted icons, or BoxBox grey icons, plus an option to show files with their default app's icon. AppImages, `.deb`, `.rpm`, and Windows `.exe` files show their own embedded icons.
- Shared freedesktop thumbnail cache and system thumbnailers (video, PDF, etc.) on Linux; native thumbnails on Windows.
- Details panel (`F11`) opens beside the file list with selectable text. Optional hover detail cards for files, folders, and sidebar drives.
- Multi-item Properties (`Alt+Enter`) walks folders for total counts and size, shows dates, owner/group, and link targets, and edits Read/Write/Run permissions (including Apply to contents) on Linux.
- Solid, Wallpaper (fit, tint, frost, accent extraction), or Transparent window background for compositor blur.
- Smooth eased animations (respects system animation settings, toggleable), spinning Refresh indicator, quiet notifications, and `Settings -> About`.

### File actions, Trash, and system integration
- Full keyboard navigation with type-ahead jump, rubber-band drag selection, select by pattern (`Ctrl+S`), invert selection (`Ctrl+I`), and `F1` shortcut help.
- Copy, cut, paste, and drag-and-drop between BoxBox and other apps as well as inside the window. Drop onto folders, panes, crumbs, sidebar places, Favorites, or Trash. Hover while dragging to open folders, crumbs, or Back, with edge scrolling, `Ctrl` copy, `Shift` move, `Ctrl+Shift` symlink, and `Alt` ask (Move/Copy/Link).
- Transfer progress panel with cancel, interactive conflict/error/low-space prompts (Skip, Rename, Replace, Merge, Retry, Apply to rest), and FAT/exFAT filename cleanup.
- Rename in place (`F2`), unused-name suggestions when creating items, Compress to ZIP, New from Template, and Send To (Desktop, mounted drives/phones/shares, or email on Linux).
- Inline "Open With" default app, recommended apps submenu, full Open With chooser with "Use as default", Open in Terminal, custom actions (KDE service menus and Thunar `uca.xml` on Linux), and confirmation prompts before running executable scripts, binaries, or untrusted `.desktop` launchers.
- Instant move to system Trash with `Ctrl+Z` undo (also undoes renames) and permanent delete with `Shift+Delete`. Sortable multi-select Trash view with batch Restore (recreating deleted parent folders), Empty Trash, and a live full/empty Trash icon.
- Native Linux system file picker (`xdg-desktop-portal` FileChooser): opt in via `Settings -> General`, `boxbox --enable-picker`, or `install.sh --set-picker` (`--disable-picker` restores the old one). Supports Open/Save dialogs, filters, list/grid views, thumbnails, zoom, and shows the requesting app's name and icon.

### Windows and Linux packaging
- **Windows (`boxbox.exe`)**: Portable ZIP with no extra runtime required. Includes tab bar window controls, inline Explorer Shell menus with icons, native Open With, Recycle Bin sync across drives, SMB network shares, Windows thumbnails, and embedded `.exe` icons.
- **Linux (`boxbox`)**: `tar.gz` with a per-user `install.sh` (no `sudo`, replaces the old Electrobun desktop entry as `io.boxbox.desktop` with PNG icons), AppImages, and an AUR package. Runs natively on Wayland, uses Vulkan (picking the compositor's GPU on multi-GPU setups), and caches Vulkan pipelines for faster starts.

## Web app

### Views and inspection
- "This Server" is now **Overview** to match the desktop app.
- Per-folder List/Grid view and sort order (optional toggle to share one view across all folders).
- Resizable and hideable list columns, plus list/grid zoom with `Ctrl +`/`-`/`0` and `Ctrl+wheel` (replaces Compact rows).
- Folder tile previews, **Customize Folder** (folder colour, searchable Lucide emblem, emblem colour), and corner emblems on special folders.
- Unboxed grid icons matching desktop sizing, file icons tinted by kind (toggleable in `Settings -> Appearance`), and two-line grid names with middle ellipsis so file endings stay readable.
- Details panel (`F11`) with selectable text, hover detail cards on files, folders, and sidebar drives (toggleable in `Settings -> General`), and multi-item Properties (`Alt+Enter`) with walked folder totals, owner/group, and accessed/changed dates.
- Spinning Refresh icon, subtle eased UI motion (respects reduced motion), quieter notifications (only failures and invisible outcomes notify), and `Settings -> About`.

### Navigation, selection, and file actions
- Rename in place (`F2`) and unused-name suggestions with live validation when creating items.
- Full keyboard navigation across list and grid with type-ahead jump, rubber-band drag selection, select by pattern (`Ctrl+S`), invert selection (`Ctrl+I`), and `F1` shortcut help.
- Back and Forward restore your selection, skip missing folders, and have right-click history menus. Middle-click folders or path crumbs to open them in a new browser tab. Start location setting (Overview or Last location).
- Right-click place menus on path crumbs, drives, places, and favourites, long-path folding into `...`, and no duplicate favourites.
- Spring-loaded drag-and-drop (hover to open folders, crumbs, places, or Back), edge auto-scroll, drop onto crumbs/places/Favorites (drops on Favorites pin the folder), with `Ctrl` copy, `Shift` move, and `Alt` ask.

## Server

- **OpenID Connect (OIDC)**: Sign in with any OIDC provider alongside or instead of passwords (`oidc.disable_password_login`), using configured `users` or `oidc.users`. Recovers automatically without a restart if the provider was down at startup.
- **NAS user and group identities**: Map BoxBox accounts (including SSO accounts) to Linux UIDs, GIDs, and supplementary groups (`nas.identities` or `BOXBOX_NAS_IDENTITY_<user>`). Each account's file access runs in a dedicated worker under its own OS identity, and share links access files under their creator's permissions.
- **Share link previews**: Public share links (`/s/{token}`) now render Open Graph and Twitter card metadata with image and video-frame previews for chat apps, plus a `public_url` setting for reverse proxies.
- **Delete shared files on expiry**: Optional toggle in the share dialog to delete a shared file when its link expires, with checks so replaced files or files still covered by another active link stay untouched. Not available in NAS mode.
- **Preserve symlinks and permissions**: Folder copies and cross-drive moves now keep symbolic links and file modes, including in NAS mode.
- **Upload session isolation**: Upload sessions are now tied to the signed-in account that started them.

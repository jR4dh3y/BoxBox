Design/surface ledger:
- SettingsStore owns a session cancellation signal, replaced by initialize and
  clearSession. Same-username relogin is a new session, token refresh is not.
- SettingsOperations binds each page/picker to that signal and its own mounted
  lifetime; a new Save/Reset/Cancel supersedes previous page work.
- Save checks cancellation around progress/paint boundaries and after IndexedDB
  completion, before applying settings or enqueuing publication. The queue
  combines operation and authenticated-session cancellation.
- An unapplied Save owns its random local image reference. Cancellation cleans
  up that staged reference, never the active preference image or another
  account's content-addressed restoration cache. Once applied, later errors
  cannot delete the current image. Existing account-specific preference keys
  and login restoration remain intact.
- Reset checks page/session validity before mutation and passes its signal to
  publication; an abandoned reset cannot publish against a subsequent login.
- Picker file reads, progress callbacks, server-list results and Apply check
  the same lifecycle. The picker only produces a draft; Save owns persistence.
  Svelte destroys the lazy picker branch with its parent.
- Publication state is absent/pending(source)/completed, keyed by account.
  Pending retries require the exact current source. The existing account-specific
  localStorage key retains the nonempty source
  for pending intent and an empty string for completed intent (an image source
  cannot be empty). Existing failed-upload markers remain readable. There is
  no pending-marker deletion or fallback that can expose an old intent.
  Completion remains durable across reload when removeItem is blocked.
  Completion is recorded for its captured
  account after acknowledged reconciliation even if a newer draft was edited.
- Memory remains usable if browser publication persistence is unavailable.
  Genuine transport failures leave pending state and local bytes intact.
  Completed publication accepts subsequent authoritative remote deletion.

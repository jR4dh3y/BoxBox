## Missing or partial, ranked
1. **Keyboard navigation and selection** — Home/End/PageUp/PageDown, Ctrl+Arrow, Ctrl+Space, Shift+Left/Right, and type-ahead are absent or incomplete, making large folders difficult to operate from the keyboard. (Known.)
2. **Shift+Delete and destructive-action parity** — permanent deletion from normal folders is missing; the web path trashes local files and offers no permanent-delete shortcut outside Trash. (Known.)
3. **Location suggestions** — path completion is absent, including hidden-folder suggestions when typing a dot prefix. (Known.)
4. **Show in folder selection** — launch opens a containing folder but does not select the requested file. (Known.)
5. **Drive naming** — stored custom labels and the Rename/Reset Name context actions are missing. (Known.)
6. **Rename and multi-selection details** — rename still uses a dialog instead of inline editing; Alt+Enter does not summarize multiple selections. (Known.)
7. **Preview navigation and zoom** — image zoom and previous/next file controls are absent. (Known.)
8. **Slow/error loading feedback** — folder errors have inline Retry, but the delayed spinner and shared `LoadError` presentation are incomplete. (Known.)
9. **Drop targets** — folder-row/tile drops from another app and complete internal pane/folder move/copy affordances are partial. (Known.)
10. **Upload and data lifecycle parity** — native import is present, but the browser upload picker, precise refresh/announcement behavior and cache-confirmation selection pruning are not equivalent or verified.

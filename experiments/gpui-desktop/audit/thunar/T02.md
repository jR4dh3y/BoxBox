## Missing or partial, ranked

1. **Bulk empty Trash and drop-to-Trash are absent.** Both are common, direct ways to manage a desktop Trash; GPUI only deletes Trash entries one at a time.
2. **Trash status is not kept current outside the GPUI window.** Thunar updates an empty/full indicator from Trash change notifications; GPUI loads on open or refresh.
3. **Custom actions are absent.** User-defined, file-filtered shell commands and their field-code expansion are a major power-user feature in a native file manager.
4. **Wallpaper actions do not integrate with the desktop environment.** GPUI can set its own background, but cannot set XFCE/GNOME desktop wallpaper from a selected image.
5. **Middle-click navigation and directional gestures are absent.** They provide quick tab and folder navigation without reaching the toolbar or keyboard.
6. **The Menu key and Shift+F10 do not open the context menu.** Keyboard users lose the standard context-menu route.
7. **The icon view lacks filename type-ahead search.** The UI map already records this gap; Ctrl+F is a separate folder-search flow.
8. **Right-click on empty space leaves the old selection active.** The menu looks like a folder menu while subsequent operations can still inherit the prior selection.
9. **Dialog Ctrl+W, inline rename, and icon zoom are missing.** These are familiar desktop interactions; inline rename is already listed in the UI map.
10. **Neighboring preview images are not prefetched.** This may make keyboard and pointer browsing feel less immediate.
11. **Thunar's translation and themed-icon registration are missing or partial.** They affect localization and desktop identity but are less central to file operations.
12. **Grid spacing is not GTK-style configurable.** GPUI has spacing, but users cannot tune it through GTK theme style properties.

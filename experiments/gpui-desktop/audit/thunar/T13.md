## Missing or partial, ranked

1. **Rows 30–37: folder-aware incoming DnD.** GPUI can import at the pane level and export URI lists, but it lacks Thunar’s item targets, Copy/Move/Link/Ask semantics, hover-to-open, edge autoscroll, and common X11 drop formats. The row-drop portion is already **known**.
2. **Rows 11–14, 16, 38, 55: folder navigation and state continuity.** Per-directory preferences, scroll/selection restoration, selecting created items, deleted-folder fallback, and selecting a Show in folder target are important daily recovery behaviors.
3. **Rows 2–6: keyboard selection and location entry.** Pattern selection, inversion, type-ahead, and the missing focus/navigation bindings make keyboard-heavy file work materially less complete; several key gaps are already **known**.
4. **Rows 7–10, 19–21: sorting and view control.** GPUI has basic sorting, but lacks Thunar’s full arrange menu, configurable hidden-last behavior, per-folder settings, and mouse-wheel navigation/zoom.
5. **Rows 40–48: status, search labels, and file metadata presentation.** The current bar reports only counts and regular-file bytes; it lacks the configurable details and display preferences users rely on to identify and compare files. Status-bar parity is **known**.
6. **Rows 25–28, 32–33: mouse and visual feedback.** Single-click activation, middle-click open, right-drag, user-configurable drag mode, drop highlighting and responsive drag navigation are common desktop conventions.
7. **Rows 22–24, 52, 57: grid appearance and file identity cues.** Zoom, thumbnail framing/preload, per-file color highlights and scrollbar behavior are lower-priority than navigation and transfer, but help users browse large photo-heavy folders.

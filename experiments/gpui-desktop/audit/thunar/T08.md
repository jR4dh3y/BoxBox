## Missing or partial, ranked

1. **Transfer conflict recovery** — Replace, rename, merge, skip-all, retry, and remembered choices cover routine copy/move conflicts; GPUI currently offers only Skip or Keep both (rows 20–22).
2. **Reliable operation recovery** — Thunar has configurable multi-step undo/redo across copy, move, create, link, Trash, and rename, with warnings for irreversible outcomes; GPUI only undoes one Trash or rename action (rows 27–29, 43–48).
3. **Recoverable delete and Trash failures** — Per-item retry/skip and the permanent-delete fallback prevent a batch from stopping at its first failure; GPUI returns the first error and does not fall back when Trash fails (rows 8, 10, 13–14, 26).
4. **Native job controls and feedback** — File-name progress, file-count percentages, pause/resume, and completion sounds make long jobs understandable and controllable; GPUI provides byte progress and cancel only (rows 16–19, 24).
5. **Breadcrumb mouse and drag behavior** — Middle-click, context menus, URI drag/drop, and one-second spring-loading are familiar Linux file-manager interactions, all missing from GPUI (rows 53–57).
6. **Transfer concurrency and recovery during errors** — Thunar's job model can pause or schedule work while prompts resolve; GPUI guards operations with a single busy state and has no in-job recovery (rows 17, 20–23; workspace/operations.rs:617-681).
7. **Free-space and file metadata parity** — Thunar reports free space, can warn when size is unknown, and uses GIO MIME types; GPUI lacks the free-space line and uses extension-based types (rows 23, 39, 41–42).
8. **Search completeness and matching** — GPUI's 1,000-result cap, whole-query substring matching, always-recursive traversal, and in-mount symlink following differ from Thunar's term-based, configurable no-follow search (rows 35–38).
9. **Listing resilience and recent files** — Thunar can continue after individual scan errors and resolves Recent targets; GPUI fails the listing on an entry error and has no Recent location (rows 3–4).
10. **Creation from templates and overwrite recovery** — Thunar can create from templates and recover from occupied names; GPUI creates empty files/folders and returns an error on collision (rows 6–10).
11. **Permissions and ownership editing** — Recursive chmod/chown with per-item recovery is useful for desktop file administration; GPUI has no matching editor or operation (rows 30–31).
12. **Breadcrumb legibility and location preference** — Full-name tooltips, middle ellipsis, active crumb styling, and a remembered bar mode help with deep paths; GPUI clips labels and has no persisted mode (rows 49–52).
13. **Known permanent-delete shortcut gap** — Shift+Delete outside Trash is a known missing GPUI entry point (row 63; UI_MAP.md:32).
14. **Known file-operation UI gaps** — Inline rename and folder-target drag/drop are already listed in UI_MAP.md's Still to do section; this chunk additionally shows that Thunar supports folder breadcrumb targets (rows 33, 55–57).

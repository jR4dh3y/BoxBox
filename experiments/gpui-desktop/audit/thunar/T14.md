## Missing or partial, ranked

1. **Transfer conflict recovery and directory merge** — Replace, rename, merge, skip-all and remembered choices are routine for a file manager; GPUI currently offers only per-item Skip or Keep both (rows 44–45).
2. **Transfer recovery and free-space handling** — Thunar can warn before running out of space and retry or skip per-item failures; GPUI aborts on provider errors without that recovery (rows 39, 46, 48).
3. **Shared freedesktop thumbnail integration** — Standard cache Move/Copy/Delete/Cleanup keeps thumbnails coherent across desktop applications, and thumbnailer discovery supports installed desktop thumbnailers; GPUI’s renderer and cache are private to the app (**known**, rows 20–28).
4. **Transfer controls and useful progress** — Pause/resume, current-file phases, transfer rate and remaining time help users manage long transfers; GPUI shows byte percentage and cancellation only (rows 36–40).
5. **Safe move fallback and metadata preservation** — Cross-filesystem move fallback, symlink-safe copying, timestamps and trusted launcher handling prevent failed or degraded moves; GPUI covers some local copy semantics but lacks broader GIO behavior (rows 41–43, 47).
6. **Integrated terminal and SSH synchronization** — The embedded shell can follow file-manager navigation, send its own CWD back to Thunar and connect to SFTP sessions; GPUI only opens an external terminal at a folder (rows 1–15).
7. **Toolbar customization** — Reordering, hiding and adding toolbar actions lets users adapt a core workspace control; GPUI has no equivalent editor (rows 29–35).
8. **Device-aware transfer scheduling** — Thunar can serialize work based on source/destination devices and preferences; GPUI only blocks overlapping workspace mutations (row 50).
9. **File-name legibility and inactive selection** — Extension-preserving middle ellipsis, explicit RTL alignment and inactive-window selection colours improve dense desktop browsing; GPUI has basic clamping/truncation and selection styling (rows 16–19).
10. **Thumbnail policy controls** — Service MIME/scheme discovery, per-size batching, file-size caps and in-flight cancellation are absent from GPUI’s extension-gated, in-memory thumbnail requests (rows 24–28).
11. **Transfer undo and Trash restoration recovery** — Thunar commits transfer history and can restore a deleted parent on untrash; GPUI does not undo paste operations and lacks this restore prompt (rows 49, 51).

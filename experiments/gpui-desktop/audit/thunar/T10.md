## Missing or partial, ranked

1. **Full properties inspection and file metadata (rows 65–74):** native users need MIME/open-with, symlink and Trash origins, timestamps, allocated size, directory totals, filesystem capacity, permissions and refresh behavior in the Properties action. 2. **Transfer pause, queueing and safe concurrency (rows 25–27, 52–59):** queued work, pause/resume, per-file status, verification, error prompts and device-aware parallelism matter for long or removable-drive copies; GPUI currently has coarse copy/move progress and cancellation.
3. **Recursive permissions and shell execution security (rows 29–30):** recursive permission defaults and explicit safe handling of executable scripts protect users from expensive accidental changes and unsafe launch behavior.

## Missing or partial, ranked

1. **Bulk rename and safe preview/conflict gating** (rows 20–36). Thunar can preview many changes, catch listed-name collisions, and execute or recover the batch; GPUI currently accepts only one selected item for rename.
2. **Session-manager restore/save** (rows 42–46). Restoring windows, tabs and active tab through the desktop session manager is a core Linux desktop continuity contract.
3. **Send To desktop-app integration** (rows 38–41). Users expect compatible installed targets for the current selection, including MIME and URI constraints.
4. **Unmounted-device icon state** (row 49). Fading an unmounted volume gives a quick, standard cue about whether it is ready to browse.
5. **Themed shortcut/device icons** (rows 47–48). Resolving device icons and symbolic variants from the desktop icon theme better matches the host desktop and device type.

## Missing or partial, ranked
1. **Hierarchical sidebar and current-folder tracking** (rows 1–3, 10). A native file manager needs folder-tree navigation and a way to keep the active path visible; GPUI has only flat places and roots.
2. **Tree keyboard navigation and device actions** (rows 6–9). Arrow-key expand/collapse and keyboard mount/unmount are useful for keyboard-first use and accessibility.
3. **Folder-target drag and drop** (rows 14–16). Dropping on a specific directory with copy/move/link choice, timed expansion and autoscroll is a core Linux file-manager workflow. **Known** from UI_MAP for pane folder drops.
4. **Tree context actions and delete semantics** (rows 5, 13). Device mount state, Trash/properties and permanent deletion should be available from the selected sidebar row. **Known** for Shift+Delete.
5. **Hidden and backup entry handling** (row 11). The current toggle misses backup files that do not begin with a dot.
6. **Path entry expansion and integrated search mode** (rows 36–37). Home/user/environment expansion and multi-term `Search:` input are fast, familiar ways to navigate and find files.
7. **User-configurable custom actions** (rows 26–32). Power users rely on reusable commands, file-type filters and shortcuts in file-manager menus.
8. **Shared desktop bookmarks** (row 35). Reading GTK bookmarks avoids maintaining a separate sidebar list from other Linux applications.
9. **File metadata and ownership details** (rows 34, 44–45). Ownership, permissions, type details and selection summaries matter when inspecting and managing files.
10. **Zoom and refresh fidelity** (rows 21–22). Adjustable density and full metadata refresh help users inspect folders and recover stale file information.
11. **Collision-safe naming and compound extensions** (rows 38–39). Automatic names prevent failed create/copy actions and preserve archive suffixes.
12. **Date/status preferences and geometry persistence** (rows 40–41, 44–47). These improve at-a-glance scanning and preserve a user's preferred window layout.

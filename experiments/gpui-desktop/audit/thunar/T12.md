## Missing or partial, ranked

1. **GVfs devices and network locations (#7, #8).** A native file manager needs to browse SMB and MTP mounts, not only UDisks block filesystems. Encrypted-volume unlocking is also absent. Known in UI_MAP.md:23.
2. **Sidebar context actions (#23).** Thunar exposes device mount actions, folder Properties, shortcut management and Empty Trash from the relevant row. GPUI has direct open/eject/unpin controls, but no sidebar context menu.
3. **Folder size calculation (#32–#37).** GPUI cannot calculate recursive folder sizes or report file/folder totals, allocated size, unreadable contents, or cancellation. This is useful for selected items and Properties.
4. **Keyboard access (#21–#22).** Thunar can open selected sidebar entries with Up/Down and provides the keyboard popup menu. GPUI has no sidebar row focus or keyboard menu path. Known keyboard work in UI_MAP.md:33–35, 185.
5. **Sidebar file drops (#26–#28).** Users cannot pin a dropped folder or drop files onto a sidebar destination. Thunar accepts standard URI lists, validates folders and reports a clear failure. Known folder-row drops in UI_MAP.md:29–30.
6. **Bookmark interoperability and management (#13–#17, #25).** GPUI stores favorites in its own JSON file. It does not follow edits to GTK’s shared bookmarks, rename a shortcut, or reorder favorites by drag.
7. **Per-entry visibility (#9, #24).** GPUI can fold sections and unpin favorites, but cannot hide and restore individual places, devices or favorites.
8. **Useful sidebar details (#10–#11).** Thunar gives device identifiers and free-space tooltips and can show threshold-coloured usage bars beside devices. GPUI shows capacity elsewhere in This PC.
9. **Recent files (#6).** Thunar offers a Recent place. GPUI has no matching shortcut.
10. **Middle-click navigation (#20).** Thunar lets the user choose a tab or window and reverse the choice with Ctrl.
11. **File-size display choices (#32).** GPUI uses 1024-based division with KB/MB labels and no binary/decimal setting. Thunar follows the configured unit preference.
12. **Sidebar icon preferences (#12).** Thunar lets users change shortcut icon size, emblems and symbolic icons. GPUI uses fixed icons.
13. **Shortcut path tooltips (#10, #43).** GPUI does not show the target path or explanatory text when users hover a sidebar row.
14. **Overlay scrolling preference (#44).** GPUI scrolls the sidebar but does not expose Thunar’s preference or adjust trailing padding when its scrollbar appears.

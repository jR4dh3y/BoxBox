## Missing or partial, ranked

1. **Rows 5, 18, 49, 56 — GVFS/network/removable device integration and mount authentication.** A Linux file manager should browse the URI schemes its desktop provides, identify device types, and handle slow/removable and encrypted volumes. GPUI currently has local mounts and UDisks2, but no GVFS network/MTP mount browsing or unlock flow. `known` in UI_MAP.
2. **Rows 1–3 — Recent, GTK bookmarks, and native virtual-location semantics.** These are common sidebar/navigation locations; GPUI's places and Trash cover only part of Thunar's location model.
3. **Rows 35–43 — system icons, thumbnails, and file emblems.** Theme/MIME icons, shared thumbnails, local/remote thumbnail policy, and status emblems are central to native file recognition. GPUI has extension icons and generated grid thumbnails, but lacks shared freedesktop cache and GIO metadata visuals. `known` for shared thumbnails in UI_MAP.
4. **Rows 9, 24 — destination filesystem naming limits and FAT-compatible transfer names.** Without filesystem-aware naming, users hit avoidable failures copying or creating names on removable and Windows-formatted volumes.
5. **Rows 16–17 — desktop application discovery/launch semantics.** GPUI already uses XDG entries and GIO launch, but desktop visibility filtering and last-used/default handler behavior still differ across environments.
6. **Rows 27–30 — robust history recovery and destination menus.** Stale locations should not trap navigation, and history menus save repeated back/forward clicks. Stale-path pruning is absent; history menus are `known` in the UI parity task.
7. **Rows 19–23 — launcher permissions and file metadata/XDG directory synchronization.** Copies of launchers, custom file metadata, and renamed XDG special directories should keep their OS behavior.
8. **Rows 31, 51 — accessibility roles and label relationships.** Screen-reader users lose structural and form-control context in the GPUI UI.
9. **Rows 32–34 — adjustable icon-grid zoom and text layout.** Fixed-size two-line tiles are usable, but do not offer Thunar's zoom and “text beside icons” preferences.
10. **Rows 8, 41–42, 46, 50 — clipboard/drop and keyboard interaction edges.** GPUI handles common file clipboard formats and pane drops, but remote URI lists, keyboard-anchored menus, text action sensitivity, hidden-file dimming, and folder-row/tile drop affordances remain incomplete. Drop-on-row/tile is `known` in UI_MAP.
11. **Rows 10–14, 25–26, 44–48, 52, 54, 57–59 — remaining transfer/display details.** Folder Properties storage details, post-copy integrity verification, naming/copy temporary-file conventions, automatic icon refresh, long-name dialog layout, split-view reset, and theme-derived colors are lower priority than device, icon, and navigation integration.

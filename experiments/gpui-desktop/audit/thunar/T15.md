## Missing or partial, ranked

1. **Expandable directory navigation in the sidebar** (rows 3–7, 9): GPUI has no folder tree, so users cannot expand nested folders, reveal the current path, or reuse recently loaded branches.
2. **Native volume and network integration** (rows 1, 12–13): UDisks2 mount/eject is present, but GVfs network/MTP mounts, encrypted-volume unlock, Network-root grouping, and nested volume browsing remain absent. The transport gaps are known in UI_MAP.
3. **Folder metadata and sort parity** (rows 15–24, 26–27): owner, group, permissions, location, richer date fields, configurable folder counts, hidden-last, and sorting by the extra columns are missing or partial.
4. **Search matching and live result behavior** (rows 28–33): type-ahead, diacritic-insensitive term matching, minimum query length, result limits, streaming results, and per-result nested change tracking differ or are missing.
5. **GIO hidden-file semantics** (row 11): GPUI filters dot-prefixed names only and cannot preserve hidden intermediate directories in an expanded navigation tree.
6. **System locations** (row 1): Recent is missing, and Network is missing with the currently supported local device integrations.
7. **Tree row drag targets** (row 35): external files can be dropped on the pane, but not onto a folder row.
8. **Presentation and scrolling details** (rows 2, 10, 14): loading/root styling, the overlay-scroll preference, and a Trash icon state are small but visible differences.
9. **Delayed folder-load feedback** (row 36): GPUI has an error and retry path but no delayed spinner for slower loads; this is a known gap in UI_MAP.

## Missing or partial, ranked
Most important first. Each has one line on why. Rows are from the table above.

1. **Bulk rename** (rows 63-64, 67-73, 74-90, 91-111, 112-118, 119-134). The whole `thunar-sbr` set (case, insert or overwrite, numbering, remove, search and replace with regex, date) is missing, and GPUI refuses rename for more than one selection (operations.rs:199). Power users rely on it, and it is not in UI_MAP "Still to do".
2. **`.desktop` launch safety** (rows 26-36). Execute-bit gating and GIO trust are missing, and GPUI opens `.desktop` files through `xdg-open` with no check (media.rs:155-160). Whether that runs a non-executable launcher was not tested, so verify before shipping. Security-relevant.
3. **Image size and decoded type in Properties** (rows 44-47). Dimensions are the most-asked-for image fact. `image` is already in Cargo.toml:15, so header dimensions need no new dependency. Type is extension-only today (format.rs:196-197).
4. **Send by mail with optional ZIP** (rows 139-171). Missing entirely. Use `org.freedesktop.portal.Email` or `xdg-email`, not the `MailReader` path. Avoid the bugs in rows 151 (NULL hole drops items), 155 (kept staging folder), 136 (wrong EFBIG text) and 159 (raw wait status).
5. **EXIF fields in Properties** (rows 48-51). Date Taken and camera data are what photo users look for. No EXIF crate in Cargo.toml, so this needs a new dependency.
6. **Accessibility labels** (rows 38, 54). App-wide, not specific to these plugins. Neither src nor Cargo.toml has an AT-SPI or accesskit path, so screen readers cannot name any field in the dialogs.
7. **`.desktop` field editor** (rows 6, 11-25). Missing. The save rules (keep translations, raw Exec, empty removes key, Enter and focus-out save, race guard, atomic write) are worth copying. Use persist.rs for the write, not the `fopen` in row 24.
8. **Multi-file ZIP** (rows 142, 147-149). Partial. Single-folder "Download as ZIP" works (ui/overlays.rs:101-111), but there is no multi-file archive and no archive cancel.
9. **Mnemonics and Alt+letter focus** (rows 37, 87, 98, 111, 118, 121, 133). Missing across all dialogs. Lower value than rows above, but the Thunar labels are a fair checklist.
10. **Tooltips on fields** (rows 7, 86, 130-131). Missing. Several tooltips explain formats and rules that users cannot otherwise discover (date format, regex, trust).
11. **Image Type column** (row 44). Partial. Shows an extension label, not the decoded format name.
12. **Long property values** (row 53). Partial. Value rows have no ellipsis (ui/overlays.rs:162-168). Not rendered to confirm.
13. **Selectable property values** (row 52). Missing. Copying a path or camera model from Properties is not possible.
14. **Live refresh of Properties** (row 2). Missing. Low value.
15. **i18n of dialog strings** (row 60). Missing. Low value until translations exist.

Bugs in Thunar to avoid copying (from reading, not running): rows 71 (title-case digit), 81 (uninitialised `tm`), 103 (strtoul accepts sign and spaces), 116 (remove highlight), 126 (regex ignores case checkbox), 129 (dead invalid-regex message), 151 (NULL hole), 155 (kept staging folder), 136 (EFBIG message), 159 (raw wait status).

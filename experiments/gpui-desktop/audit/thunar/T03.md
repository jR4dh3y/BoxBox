## Missing or partial, ranked

1. **Selected-item launch semantics (`#8`, `#42–44`, `#48`).** FileManager1 and command-line launches need to select the requested item, honor method-specific behavior, and preserve desktop activation context.
2. **Permanent deletion and Trash management (`#17`, `#22`).** Native users need both a deliberate Shift+Delete path and an explicit, confirmed Empty Trash operation.
3. **Open selected folders in tabs/windows (`#3–4`, `#53`).** These are standard file-manager actions, including a safeguard before opening many windows.
4. **Multi-item Properties and bulk rename (`#12`, `#15`).** Both operations are useful for routine file management; GPUI currently limits these workflows to one item.
5. **Create from XDG Templates (`#25–26`).** Template files and their folder organization are a core desktop workflow and should follow the user's configured Templates location.
6. **Default app and executable action parity (`#5–7`, `#54`).** GPUI has Open With, but its action availability and explicit execute/launcher flows are narrower than Thunar's MIME-aware menu.
7. **Restore and Show (`#21`).** Users often need the restored item opened immediately to continue working.
8. **Send To destinations (`#9–11`).** Shortcuts, removable media, desktop links, and matching applications are common desktop-file-manager integrations.
9. **Session and window behavior (`#40`, `#45–46`).** Daemon/quit controls and restoration of tabs, split panes, and focus support normal desktop lifecycle expectations.
10. **Delayed progress and operation history (`#35–38`).** GPUI reports coarse status, but long transfers lack Thunar's delayed shared progress presentation and broader operation-history coverage.
11. **Recent actions and custom actions (`#23`, `#56`).** Useful but less central than core file operations; removing a Recent entry should not delete its file.
12. **Shortcut aliases and proposed create names (`#24`, `#29`).** Compatibility aliases and collision-free initial names reduce friction for keyboard-first use.
